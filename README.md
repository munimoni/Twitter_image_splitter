# Twitter_image_splitter

1枚の画像を縦線で 2〜4 枚に分割し、Twitter（X）のカルーセル表示でどう見えるかを確認してから保存できるツールです。横長の画像を分けて投稿すると、スワイプするたびに絵がつながって見える投稿になります。

🔗 **公開ページ:** https://github.com/munimoni/Twitter_image_splitter

## 使い方

### 1. 画像を選ぶ

次のいずれかで画像を読み込みます。

- 「ここに画像をドロップ」の枠にファイルをドラッグ＆ドロップ
- 枠をクリックしてファイルを選択
- クリップボードの画像を貼り付け（Ctrl+V / ⌘V）

対応形式は JPG / PNG / WEBP です。読み込むとサムネイルとサイズが表示され、「別の画像を選ぶ」でやり直せます。

### 2. 枚数を決める

「2枚 / 3枚 / 4枚」から選びます。最初は等しい幅で切り分けられます。

### 3. 分割位置を調整する（任意）

右側の「分割位置」で、画像の上に出ているつまみ（▽）を左右にドラッグすると切る位置を動かせます。ドラッグ中はその位置のピクセル値が表示されます。等分に戻したいときは「均等に戻す」を押してください。

### 4. 見え方を確認する

下段のスマホ風プレビューで、投稿したときのカルーセル表示を確認できます。

- 画像をドラッグ／スワイプ、‹ › ボタン、または ← → キーで画像を送れます
- 「Xの表示テーマ」でブラック / ダークブルー / ライトを切り替えられます

隣の「分割後の画像」では、実際と同じ 4px の隙間で並べた状態と各画像のサイズを確認できます。

### 5. 保存する

「すべて保存」を押すと、分割後の画像を 1 枚ずつ連続でダウンロードします。ファイル名は `元の名前_1of4.png` のような連番になるので、その順番で X に添付してください。1 枚だけ保存したい場合は「分割後の画像」の各画像の下にある「この画像を保存」を使います。

> ブラウザが「複数ファイルのダウンロードを許可しますか」と確認してきたら許可してください。ブロックされた場合は 1 枚ずつ保存できます。

## 特徴

- HTML 1 ファイルだけで動作。外部ライブラリ・ビルド不要
- 画像はブラウザ内だけで処理され、サーバーには送信されません

## 注意

X の表示仕様はアプリ版・ブラウザ版や時期によって変わることがあります。プレビューはあくまで目安です。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。
